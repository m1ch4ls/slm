# Local Markdown Issue Tracker

- One feature per directory: `.scratch/<feature-slug>/`.
- The PRD is `.scratch/<feature-slug>/PRD.md`.
- Issues are `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, numbered from `01`.
- Put `Status: <label>` and `Execution: AFK | HITL` near the top of each issue.
- Append discussion under `## Comments`; do not rewrite historical decisions.
- Issues should be thin, complete, independently verifiable vertical slices.
